**Parent Hub**: [[SEM 7 Master MOC]]

---

## 📌 Course Overview
Project Phase – I (BTCOS708) is the initial phase of the capstone final year project (or industry internship track BTCOF801). During Semester 7, students select a research problem / engineering domain, conduct a comprehensive literature survey, define system requirements, design system architecture, and present Phase I progress.

---

## 📋 Phase I Key Milestones & Workflow

1. **Domain Selection & Problem Definition**:
   - Identify domain (e.g., AI/ML, Cloud Systems, Big Data Pipelines, Deep Learning Applications).
   - Formulate Problem Statement & Objectives.

2. **Literature Survey & Prior Art Review**:
   - Review 5+ peer-reviewed IEEE/Springer/ACM papers.
   - Summarize research gaps and comparative study.

3. **System Requirements & Architecture Design**:
   - Hardware & Software Specifications.
   - High-Level System Architecture, Dataflow Diagrams (DFD), UML Diagrams.

4. **Phase I Progress Report & Seminar Defense**:
   - Prepare Phase I Seminar Presentation (PPT).
   - Draft Project Report Part-I submitted to department guide.
